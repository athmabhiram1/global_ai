Wire this console to the real sidecar

Everything renders through one adapter (CC in the source). The mocks already return the exact shapes documented in docs/ARCHITECTURE.md §6 / §14 — going live is a config change, not a rewrite.

1
Point the adapter at your sidecar

Serve this file from the sidecar's / route (or any static host) and set the constants in the marked block at the top of the script.

2
Flip useMock to false

Each method switches to a real fetch with Authorization: Bearer <CC_ADMIN_TOKEN>.

3
Allow the origin

The sidecar must return Access-Control-Allow-Origin for this page's origin — or serve the file itself from :8090.

// ── integration block (top of <script>) ──────────────
const CONFIG = {
  baseUrl: 'http://localhost:8090',  // cc-sidecar
  token:   '<CC_ADMIN_TOKEN>',
  useMock: false,                    // ← flip this
};

// endpoints the UI consumes (ARCHITECTURE.md §14)

Live wiring keeps the same render path: the ledger polls decisions, the drawer loads decisions/:id, feedback POSTs to feedback, and the autopsy calls autopsy and renders whatever sentences your sidecar returns.
